# Employee Burnout Prediction
An ML project that predicts an employee's Burn Rate (0 to 1) from work details like designation, resource allocation and mental fatigue score, using Linear Regression.

## How to run
1. pip install -r requirements.txt
2. python Python_Code/project.py
3. python Python_Code/project_1.py (enter employee details to get the burnout risk level)
